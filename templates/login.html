Iris Flower
Prediction

A Machine Learning based web application that predicts the species of an Iris flower using its physical measurements. After logging in, users can enter the flower measurements and the trained model predicts the most likely Iris species.

🌱 Dataset

The Iris dataset contains measurements of different Iris flower species.

🤖 Machine Learning

A trained classification model is used to identify the flower species.

📊 Input Features

Sepal Length, Sepal Width, Petal Length and Petal Width.

🌸 Predictions

The application predicts Setosa, Versicolor or Virginica.

✨ Project Features
✓ Simple and user-friendly interface
✓ Machine Learning based prediction
✓ Fast flower classification
✓ Secure login before prediction
